Normal tissue complication probability curve

NTCP curve; Lyman-Kutcher-Burman curve

The fitted sigmoid probability of a named normal-tissue complication against dose, usually Lyman-Kutcher-Burman with a volume-effect parameter.

How to read it

  • Same sigmoid form as TCP, shifted to higher dose
  • TD50 is the dose giving a 50% complication rate
  • The n parameter sets serial or parallel behaviour
  • Drawn with TCP, the gap is the therapeutic window

What it hides

  • Which complication, and how it was graded
  • The dose distribution, reduced to one effective dose
  • The fitted cohort's fractionation and follow-up

Reach for it when

  • Showing what a dose escalation would cost
  • Ranking plans that already meet every hard constraint

Avoid it when

  • Comparing values fitted to different endpoints
  • Organs whose DVH shape breaks the dose reduction
R
plot(dose, pnorm((dose - td50) / (m * td50)), type = 'l')
Python
matplotlib.pyplot.plot(dose, scipy.stats.norm.cdf((dose - td50) / (m * td50)))
