Sina plot

Points jittered horizontally, with the jitter width at each height set by the local density — a violin's silhouette made of real observations.

How to read it

  • Read the shape as you would a violin
  • Every mark is one observation
  • Width and point concentration reinforce each other

What it hides

  • Very little — with no area fill it cannot fabricate density from few points

Reach for it when

  • Almost anywhere you were about to draw a violin under a few hundred points
  • Often the better default

Avoid it when

  • Very large n, where the points saturate the available width
R
ggplot(d, aes(group, value)) + ggforce::geom_sina()
