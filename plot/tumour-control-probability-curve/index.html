Tumour control probability curve

TCP curve

A fitted sigmoid giving the modelled probability that a tumour is controlled, as a function of delivered dose.

How to read it

  • Probability climbs over a narrow dose band
  • D50 is the dose giving 50% control
  • Steepness is gamma-50; steeper leaves less margin
  • The curve is a model fit, not measured points

What it hides

  • The spread of patient radiosensitivity behind one curve
  • Fractionation — the same total dose is not the same effect
  • Fit uncertainty; confidence bands are usually omitted

Reach for it when

  • Arguing the case for a dose escalation
  • Setting beside NTCP to show the therapeutic window

Avoid it when

  • Predicting the outcome for one patient
  • Doses outside the range the model was fitted on
R
plot(drc::drm(controlled ~ dose, weights = n, fct = drc::LL.2(), type = 'binomial'))
Python
matplotlib.pyplot.plot(d, 1 / (1 + (d50 / d) ** (4 * gamma50)))
